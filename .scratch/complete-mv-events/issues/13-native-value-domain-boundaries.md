## Question

### 共同范围与精确数值域

正式编写、DSL Decompilation 与可识别的 Raw DSL Command 原生参数采用同一支持域及错误/警告规则。已有数据没有专属宽松通道；原生正常反例若被当前契约排除，须重开模型，不能用 raw 回退或静默改写掩盖。当前编辑控件可选范围、Native Saved Value、参数重确认行为与实际运行结果分别描述。

以下字段采用整数 **0..2,147,483,647**：Show Text（E101）与 Change Actor Images（E322）的 faceIndex，以及 Transfer Player（E201）、Set Vehicle Location（E202）、Set Event Location（E203）、Get Location Info（E285）的 direct x/y。负数、小数、非有限值、超过上界的数和负零 `-0` 均报错；普通 `0` 合法，不利用 JSON 序列化把负零改为零。此条只覆盖这些字段，不推广到变量读取的运行值、图片坐标、相对移动、角色 selector 或其他 JSON 数字。

目标字段声明 QML `int` 是已核验的静态事实；上界与 QML 有符号32位整数的语言类型语义对齐。接受整个非负区间是明确的有限保存能力，不声称每个数值都可由普通 picker 点选产生，也不声称目标极值载入、重确认和运行均已验证。当前图片/地图尺寸不收窄该形式域。

### 脸图、None 与素材依赖

E101/E322 正式支持原生 picker 可达的非标准尺寸脸图，包括 576×432 图片第三行 index 8..11；官方 144×144、4列2行规范不构成硬 0..7 域。素材选择与 index 独立保存，None 继续使用该参数的明确原生空素材编码，不删除 index 或自动归零。

本轮沿用 Workspace 不扫描实际素材文件或尺寸的范围，素材检查限于类别、非空名称等引用结构；不新增资产清单、读取依赖或素材漂移规则。

| 情况 | 保存与诊断 |
| --- | --- |
| 非 None，index 0..7 | 原样保存，执行素材引用结构检查；不因此声称文件存在或尺寸已通过检查 |
| 非 None，index >=8 且在形式域内 | 原样保存，warning：超过官方两行布局，当前素材尺寸未校验；不能断言一定越界 |
| None，index 在形式域内 | 原样保存独立 index，不发缺图或图片越界警告 |
| index 不在形式域内 | error，None 不豁免数值检查 |

因此，缺失图片文件、替换成一行图片后 index 6 已不适用等情况不能在本轮自动发现。原生 picker 有素材变化后调整选框并可能将超范围 index 归零的静态路径；此为参数重确认风险，不是 DSL 的保存规则，也不是已完成的真实 UI 观察。仅保存事件容器与重新确认素材参数必须分别验收。

### 直接坐标、项目引用与运行地图

| 情况 | 检查与诊断 |
| --- | --- |
| E201/E202 direct | 固定 Map Reference 必须存在；按该目标地图 Snapshot 宽高检查，x>=width 或 y>=height 时 warning 并保留；缺失引用 error |
| Map Event 内 E203/E285 direct | 按所属地图宽高检查，越界时给有条件的上下文 warning，明确“相对于所属地图越界”，不声称该地图是所有后续执行路径的运行地图 |
| Common Event 等无法确定当前地图的 E203/E285 direct | 不猜地图、不要求上下文声明，不仅因未知本身报警；形式域检查照常 |
| 使用变量指定位置 | 验证所有输入/输出变量引用，不推断其未来值或把 direct 字面量范围套到运行读值 |

所有模式维持其各自完整参数形状、互斥和 selector 规则；不新增从当前工程或声明位置隐式补地图/坐标的默认。Map Event 本身初始位置的 bounds error 保持原义，不能借它拒绝指令中已接受的越界保存坐标。既有容器不适用警告仍成立；本票不增加调用图传播、流程分析或运行成功保证。

Get Location Info 的诊断按查询类型描述后果：terrainTag/regionId 检查地图边界，越界返回0；eventId 按事件当前坐标精确查找，未命中才返回0，命中返回列表中首个事件ID；tileId 直接计算数组索引，越界可能别名到其他位置或缺值返回0。不能用某一种模式的后果概括全部查询。具体首方定位与证据强度见[地图报告](../research/command-parameters/visual-map.md#需要跟踪的前置与验收交接)。

### 完整字符串与重确认警告

E118 Label、E119 Jump to Label、E320 Change Name、E324 Change Nickname、E325 Change Profile，以及 E111 脚本条件、E122 脚本操作数、M45 移动脚本，按各自原生完整字符串槽保存。允许空串、空白、CR/LF/CRLF 和尾部字符，不新增产品字符数或行数上限；不 trim、拆成多条记录、裁尾或规范化换行。Label 匹配继续使用精确字符串。

| 原始字符串条件 | 诊断 |
| --- | --- |
| E118/E119/E320/E324/E111脚本/E122脚本/M45脚本含 LF | warning：超过目标单行控件的输入范围，重新确认参数可能改变内容 |
| E325 Profile 含两个及以上 LF | warning：按 LF 分隔超过两行，重新确认参数可能改变内容 |
| 上述任一槽含 CR | warning：控制字符在参数重确认时的保留行为尚待实测，不能断言必被删除或归一化 |
| 不满足上述条件 | 不因长度、空白或其他控制字符凭猜测新增本类 warning |

判断直接使用原串，尾部 LF 也计数，不先转换 CRLF；同字段的多个原因可合并为一条 warning。Profile 的 `"a\n"` 是两段，不触发行数 warning；`"a\n\n"` 触发；`"a\r\nb"` 仅触发 CR warning，而该串在单行字段中同时触发 LF 和 CR 原因。LF 计数是产品诊断规则，不冒充精确复现 Qt lineCount、粘贴和信号时序。

这些 warning 仅描述重新确认参数对话框的风险，不声称仅保存事件容器就会改写；warning 不修改内容或将成功操作变成失败。类型错误、缺槽/多槽等既有结构错误仍报错。Script Command Gate 继续递归适用，空脚本与不可达/非激活保存状态不豁免；Decompile 可准确表达并提示 Gate 配置要求，Compile/Check 在 Gate 关闭时拒绝。不新增脚本语法解析器、预执行或可运行性保证。

E356 Plugin Command Line 的既定完整字符串规则继续有效，本票不扩展上述 warning 矩阵到其他字段。Show Text、Scrolling Text、Comment、E355 Script 的四类物理行记录契约也不变，不把单槽字符串支持域反向推广到那些记录。

### Change EXP、默认与阶段责任

Change EXP 常量采用整数 **1..9,999,999**，不主动扩至帮助所写的 99,999,999；变量读取的运行值不受该常量控件上限约束。本体 QML 与帮助差异继续记录，真实 9,999,999/10,000,000 输入和保存实验交 08。新的正常原生域外反例须重开模型，产品选择不替代取证。

本票不新增可省略字段或 Compiler Default。所有未获批的便利默认保持显式表达；反编译只按已有明确默认省略可精确重建的状态，不能因 None、当前地图/素材状态或 warning 删除独立保存值。

沿用 06/07 的阶段责任：Decompile 在源码发布前检查完整候选及已能确定的引用/上下文；Compile/Check 基于当前 Staged Data Graph 独立重验；Push 执行既有 Freshness/Drift/写入安全规则。诊断含稳定标识、阶段、级别、事件身份及准确路径，区分支持域错误、引用失败、上下文风险和编辑器重确认风险；不新增资产检查依赖。域外样本拒绝仍区分未支持与已证违规，未知命令政策不变。

### 文档与验收交接

- 数字：0、7/8/11、2,147,483,647 与 −1、小数、2,147,483,648、非有限、负零；正式编写、原生输入、手写已知 raw 的一致诊断；不把合成极值夹具标为普通 UI 创建证据。
- 脸图：标准图/三行图/较小替换图/缺文件，None 与非零索引；非 None index>=8 的准确 warning；仅重存、重新确认 picker、游戏显示分开记录。
- 坐标：原点/边缘/地图缩小后的旧坐标；固定地图缺失与变量引用缺失；Common Event 跨不同地图调用；所属地图条件性 warning；terrain/region、tileId 及其他查询的实际后果。
- 文本：上述八种字段的空串/空白、CR/LF/CRLF、尾部换行、超普通控件行数与长字符串；原串诊断计数；Label 精确匹配；单参数 Script Gate 与四类行记录规则互不误用。
