## Question

字段基准已建立，但首方帮助和已保存样例不能证明所有编辑控件的合法值集合或所有创建路径的初值。复用同一 `references/RPGMV/RPGMV.exe` 的已定位嵌入 QML/JavaScript，聚焦查明地图事件/页、公共事件和战斗页的新建、清空与新增页默认值，以及地图页移动速度/频率、图像方向/图案/索引、条件阈值、战斗回合和 HP 条件等原生控件的枚举或上下界。

区分构造器初值、随包模板值、控件可输入范围、runtime 接受范围和真实 UI 行为；它们不一定相同。记录资源身份、文件偏移、解码边界、静态代码路径与未知项。复用已经取得的版本和资源证据，不重复 REA 连接诊断或大范围逆向。

只写一份原创研究报告，不设计最终 DSL，不执行目标程序。若静态源不足以裁定某项，明确指出最小编辑器实验，并保留该项未决。研究帮助后续选择 Compiler Default 和验证边界，不把源代码阅读声称为真实保存/运行测试。

## Answer

普通地图事件、地图页、公共事件和战斗页的工厂初值与主要属性控件范围已有静态调用链依据，见 [MV 1.6.1 原生事件的创建初值与属性控件范围](../research/event-defaults-and-limits.md)。地图空页速度为 3、频率为 3、priority 为 0；主要枚举、条件阈值、图像选择域与正常按钮路径的 1..20 页限制均有逐项资源定位。公共事件与敌群的数据库配置、分页转发和模板工厂调用链已闭合。

本票完成的是有界静态调查，不裁定最终 Compiler Default 或验证政策。底层 SpinBox 的完整 normalize 与小数精度、异常已有值的装载/保存、0/21 页导入、非标准尺寸资产、快捷事件及新工程模板复制的全部路径仍未验证。控件允许值不能自动成为原始数据的裁剪规则，工厂初值不能覆盖反编译已有数据。需要设计取舍的部分交由 [地图事件备注与完整事件页应采用什么 DSL 模型](03-map-event-page-model.md) 和 [语义无损往返与未知数据处理的精确契约是什么](06-semantic-roundtrip-policy.md)；报告的最小真实编辑器实验交由 [如何证明 MV 事件支持完整并划定实施顺序](08-completion-evidence-and-sequencing.md) 纳入验收，必要的新事实调查继续成票。
