# 02: 参数化命令函数与嵌套组合

**What to build:** Event DSL 作者可以在本地或共享模块定义命令函数，通过选项对象为不同事件传入奖励、引用和设置，并组合其他共享函数。不同调用生成各自正确的命令，仍通过普通 Compile/Check 和既有事件编译流程使用。

Blocked by: 01
Status: ready-for-agent

Parent: [跨事件的共享编写模块与参数化命令函数（第一版）](../shared-authoring-modules-spec.md)
User Stories: 4, 5, 6, 7, 8, 9, 10, 18, 19, 22, 27

- [ ] 支持具名函数声明和赋给 const 的箭头函数，既能同文件调用，也能具名导出、导入和通过导入别名调用；不把函数收集为 Event Definition。
- [ ] 支持零个参数或一个具名选项对象参数；支持参数名后的属性读取，以及一层具名属性解构和重命名。参数和返回值可带普通 TypeScript 类型声明，错误的参数类型在 Compile/Check 中可见。
- [ ] 支持箭头表达式返回体，以及由零到多个 const 声明和一个末尾 return 组成的函数块；函数内可使用参数、模块常量、既有受限表达式、DSL helper 和其他受支持函数。
- [ ] 词法绑定和调用作用域符合所支持语法的普通行为；每次调用具有独立局部值。覆盖同名局部绑定、多个调用参数以及跨模块常量的组合，不能让一次调用改写其他调用或模块常量。
- [ ] 函数可以返回用于组合的常量、配置、引用值、单个 DSL Command 或命令数组；多层函数组合及同一函数多次调用保持作者指定的命令顺序，不隐式展平数组。
- [ ] 用至少两个不同参数集的宝箱或奖励事件完成公开 Compile/Check 验证；生成命令与独立预期一致，并辅以内联写法比较。普通编译后能进入现有 Diff/Push 流程。
- [ ] 直接或间接递归明确失败，并报告有用的函数链；不能无限递归或以宿主执行代替受限求值。
- [ ] 对本阶段加载模块中的函数体检查支持范围，包括尚未调用的函数。默认参数、rest、嵌套解构、this、通用控制流、一般二元计算、模板插值、数组及宿主方法、异步、生成器、类和可变状态等规格外语法明确失败。
- [ ] 不增加函数返回函数、完整 Event Definition 工厂、批量事件生成或自动身份分配。事件仍显式声明 Entry Identity；函数调用不会生成 Common Event 或改变运行时调用关系。
- [ ] 函数源码及传递组合依赖沿用 01 的一致输入捕获和新鲜度检查。仅修改函数实现后旧产物失效；重新 Compile 能更新所有相关事件。Compile Check 保持只读。
- [ ] 基本参数、语法、绑定及函数构造错误有可靠源码位置；保留可用于后续完整调用诊断的信息。不同使用位置及后续引用、素材验证的完整来源验收由 05 负责。
- [ ] 通过现有公开 Workspace API 覆盖本地与跨模块调用，并验证既有 DSL helper、Common Event 调用和 Script Command Gate 的语义；不执行事件 JavaScript。
- [ ] 同步第一版函数语法说明和最小可编译示例，相对实际集成版本更新 Compile Contract Version，完成受影响的类型、静态和行为检查。

本票交付可使用的纯组合函数。跨三类事件容器和 Child Command Body 的完整保存形态矩阵由 03 负责；共享函数不参与的基本依赖变化票 04 不以本票为前置条件。
