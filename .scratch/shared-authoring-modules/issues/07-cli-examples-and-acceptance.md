# 07: 完成构建后 CLI、示例与使用指南验收

**What to build:** 作者可以照着公开示例完成共享值、参数化宝箱或奖励函数及嵌套组合，通过构建后的 CLI 编译并使用结果；共享源码改变后，CLI 拒绝旧产物，重新编译后正常继续。使用指南准确说明第一版语法和工作流边界，整份规格有对应完成证据。

Blocked by: 03, 04, 05, 06
Status: ready-for-agent

Parent: [跨事件的共享编写模块与参数化命令函数（第一版）](../shared-authoring-modules-spec.md)
User Stories: 26, 27, 29, 30

- [ ] 在包含所有前置票的实际集成版本上运行必要构建；构建后 CLI 可以编译一个包含共享常量、参数化奖励或宝箱函数及嵌套组合的真实 Workspace，验证退出码和独立预期数据。
- [ ] 从同一示例完成正常 Compile Check、Compile、Diff 和 Push；核对项目落盘结果，证明文档中的作者流程可用，而不只验证包内加载器。
- [ ] 构建后 CLI 至少覆盖一个仅修改共享函数或其传递依赖的失效案例：入口不变，旧产物被 Diff/Push 拒绝，诊断可读且拒绝前没有项目写入；重新 Compile 后相关事件输出更新并能正常继续。
- [ ] 核对前置票对三类事件、Child Command Body、错误定位、依赖变动及 Decompile 的公开 API 验收在当前集成上仍成立；只对整合变化、失败或尚未解决的问题补跑相关用例，不把全部 API 矩阵复制成 CLI 测试。
- [ ] 公开说明和 Sample Workspace 提供共享值、具名函数、箭头函数、选项对象、嵌套组合、错误定位与重新编译流程的可编译示例；示例中的依赖和项目引用完整可解析。
- [ ] Agent Event Authoring Skill 使用与实现一致的第一版能力，帮助作者选择源码共享与 Common Event 调用，明确编译时参数与游戏运行时条件的区别。
- [ ] 使用指南明确函数体、导入/导出和模块范围限制，不暗示支持任意 TypeScript 执行、自动事件工厂、批量 ID 分配或自动抽取重复逻辑；文档示例通过真实 Workspace 验证。
- [ ] 同步必要的新领域概念，核对 ADR 0013 的值导入边界、ADR 0002 的实际加载模型，以及其他保留的身份、Compile/Push、保存状态和 Decompile 发布约定，与最终实现一致。
- [ ] 核对 Compile Contract Version 相对于实际集成状态包含所有需要失效旧输出的变化；独立票不能仅因为选择了相同版本号就把不同契约当成一致。
- [ ] 逐项核对父规格的 30 条 User Stories、16 条 Implementation Decisions 和验收场景，指出对应完成票及验证结果。前置票遗漏或最终集成失败必须修复并验证，不能以票已关闭代替功能验收。
- [ ] 对既有内联 DSL、同文件 const、DSL namespace、类型导入、Common Event 调用及支持范围内 Event Semantic Round Trip 保留必要回归；运行与实际变更相关的类型、静态和测试检查。
- [ ] 以简短记录说明当前版本、已执行验证和任何未完成项。所有第一版必需项通过后才完成本票；不新增大型验收归档制度，也不把未执行的原生游戏验收写成通过。

本票负责集成后的可用交付，01–06 必须各自带有行为测试和完成证据。阻塞列表只记录直接前置票，01 和 02 已由这些依赖传递包含；本票不自动修改或关闭父规格。
