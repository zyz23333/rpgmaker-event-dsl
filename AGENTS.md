# Repository guidance

## Agent skills

### Issue tracker

Before reading, publishing, or resolving specs and tickets, read `docs/agents/issue-tracker.md`. Work is tracked in local Markdown under `.scratch/<feature-slug>/`.

### Triage labels

Before triaging work or setting a ticket's triage state, read `docs/agents/triage-labels.md`. Use the five default canonical role names.

### Domain docs

Before exploring the codebase, read `docs/agents/domain.md`. This repo uses a single-context layout with root `GLOSSARY.md` and `docs/adr/`.
