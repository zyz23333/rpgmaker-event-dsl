# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the strings used in this repo's local Markdown tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding string from this table. Local metadata, completion, and Wayfinder lifecycle conventions are defined in `issue-tracker.md`.

Edit the "Label in our tracker" column to change the vocabulary later.
